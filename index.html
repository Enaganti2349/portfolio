Newest · Voice AI · Coastal safety

Matsya Mitra v2.0 (మత్స్య మిత్ర)

A sovereign voice AI and coastal-safety copilot for Telugu-speaking fisherfolk in Andhra Pradesh. It combines spoken Telugu interaction, live marine data and government welfare information. Built for The Great Indian AI Internship Challenge, powered by Gnani.ai.

6AP harbours
5-stagevoice pipeline
E0–E3sea-state grades
  • Understands spoken Telugu and code-mixed "Telglish", using a phonetic lexicon of Telugu loanwords.
  • Fetches live marine data for Visakhapatnam, Kakinada, Machilipatnam, Nizampatnam, Krishnapatnam and Kalingapatnam, and grades sea state with WMO Code 3700.
  • Maps INCOIS Potential Fishing Zone data to guide boats toward productive zones and help cut diesel use.
  • Includes a rule-based welfare verifier for fishing-ban relief, accidental death insurance and the diesel subsidy.

How it works
  1. Clean the audioA 300–3400 Hz Butterworth bandpass filter and spectral noise gating remove engine rumble and wind noise.
  2. TranscribeGnani Prisma v3.0 converts Telugu speech to text, and Telglish terms are parsed.
  3. Fetch live dataConcurrent async requests pull marine telemetry and fishing-zone data for the six harbours.
  4. ReasonThe Evon LLM answers from a prompt grounded in live conditions and welfare rules, in under 55 words.
  5. SpeakGnani Timbre turns the reply into natural Telugu audio.
Generative AI · RAG

Multimodal RAG: Intelligent Chart & Document Analyzer

An end-to-end system to parse and query text and visual data in complex PDFs using FastAPI and the Gemini 2.5 Flash vision-language model.

How it works
  1. DetectPyMuPDF detects the elements on each page, and scanned pages are identified automatically for VLM OCR.
  2. SkipSmart VLM-skip logic avoids unnecessary model calls, cutting API cost.
  3. Parse in parallelGemini 2.5 Flash reads the remaining pages concurrently with ThreadPoolExecutor to raise throughput.
  4. IndexA local SQLite vector store with an in-memory embedding cache gives sub-millisecond query retrieval.
  5. ExploreA responsive three-panel interface with Figma-style zoom and pan to query the document.
